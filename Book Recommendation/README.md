# **Book Recommendation Engine**  

A machine learning-powered book recommendation engine using FAISS for vector similarity search and embeddings from the Llama2 model (via Ollama).  


## **Features**  
- Book recommendations based on similarity search.  
- Uses **FAISS** (Facebook AI Similarity Search) for fast vector similarity computation.  
- Embeddings generated by **Llama2** through the **Ollama API**.  

---

## **Requirements**  
- Python 3.8 or later  
- Libraries: `pandas`, `numpy`, `faiss`, `requests`  
- Ollama installed and running on the local system  
- FAISS pre-built with 500 book vectors for similarity search  

---

## **Dataset Details**  
- **Source:** Kaggle (7K books dataset)  
- **Vector Store:** Precomputed embeddings for **500 books**.  
- FAISS is used to store and retrieve embeddings efficiently.  

---

## **Setup and Installation**  
1. **Clone the repository:**  
    ```bash  
    git clone https://github.com/DeveloperLevin/GenerativeAI.git  
    cd Book Recommendation
    ```  

2. **Install dependencies:**  
    ```bash  
    pip install pandas numpy requests faiss-gpu  
    ```  
    make sure you have cuda installed in your system.

3. **Ensure Ollama is running locally:**  
    - Install Ollama following the instructions from their [official website](https://ollama.com/).  
    - Pull the required model:  
      ```bash  
      ollama pull llama2  
      ```  

4. **Prepare FAISS index and dataset:**  
    - Ensure the FAISS index file (`index`) is present in the project directory.  
    - Download the dataset (`books.csv`) from Kaggle and place it in the `dataset` folder.  

---

## **How to Run**  
1. Start the Ollama server:  
    ```bash  
    ollama serve  
    ```  

2. Run the application:  
    ```bash  
    python app.py  
    ```  

3. Follow the prompts to input book details. The engine will recommend similar books based on user input.
